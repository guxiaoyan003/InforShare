# 微信扫码登录 · 接入实施文档

> 服务器、域名、SSL 证书已有，本文只解决一件事：**把微信扫码登录接进现有登录页**。

---

## 一、费用：只有 300 元/年

| 项目 | 费用 | 说明 |
|---|---|---|
| 开放平台开发者资质认证 | **300 元 / 年** | 唯一支出 |
| 扫码登录接口调用 | **免费** | 不按次计费，调用量再大也是 0 元 |

服务器、域名、SSL 已有，不产生额外费用。

**这 300 元不是花在调用上，是花在资格上。** 不做资质认证，账号创建不了「网站应用」，接口根本调不了。而且是年费，第二年要续，不续名下应用会失效。

### 时间：约 2 周

| 阶段 | 耗时 |
|---|---|
| 注册开放平台账号 | 当天 |
| 开发者资质认证 | 1–7 个工作日 |
| 网站应用审核 | 约 7 个工作日 |

## 二、前置条件

| 条件 | 要求 |
|---|---|
| 企业主体 | 需营业执照，个人开发者做不了 |
| 已备案域名 | 授权回调域必须是自己的已备案域名，**不能填 IP** |
| 可访问的官网页面 | 审核员会真的点开看 |

**特别注意：不能只有一个登录页。** 申请网站应用要填「应用官网」，审核员打开如果只看到一个登录框，会被判定"网站不完整"驳回。得有公司介绍、主营业务、联系方式这类内容，登录入口放在 `/login`。

# 企业认证· 天眼查

### 一、费用 

0.10 元/次

## 二、前置条件

**流程:** 企业实名认证 → 申请「企业三要素验证」接口权限 → 配置服务器出口 IP 白名单 → 拿 Token

**企业实名认证提交认证材料**： 营业执照扫描件、企业全称、统一社会信用代码、法定代表人姓名、身份证号 、 经办人信息及手机号  3. 验证主体真实性

审核需要 **1–3** 个工作日

## 三、API 输入参数

1. 营业执照上的 公司编号（统一社会信用代码/注册号/组织机构代码）
2. 企业名称
3. 法人名
