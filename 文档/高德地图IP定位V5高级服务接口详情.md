## 高德地图IP定位V5高级服务接口详情

### 申请流程：需工单进行商务咨询

V5**不能**像V3那样在控制台自助创建Key后直接调用。官方文档明确提示：“高级 IP 定位属于高级服务接口。如需申请，请通过**工单**进行商务咨询”。

因此，申请的第一步是拥有高德开放平台开发者账号，然后**提交工单**说明使用场景和需求量，由高德进行商务审核并开通权限。权限开通后，才涉及创建**Web服务API**类型的Key。这意味着**商务咨询和权限审核是前置且必要的一步**。

### 使用方法：三步调用，但`ip`参数为必填

获得权限和Key后，调用流程与V3的结构一致，官方说明为三步：

1. **拼接HTTP请求URL**，将Key作为必填参数。
2. **发送GET请求**。
3. **接收并解析返回数据**（JSON或XML，编码统一为UTF-8）。

官方给出的服务示例如下：
`https://restapi.amap.com/v5/ip/location?key=<用户的key>&ip=114.247.50.2&type=4`

一个关键区别是：在V5中，**`ip`参数是必填的**，不支持像V3那样省略`ip`来自动获取请求方的客户端IP。

### 输入参数（请求参数）

官方文档页面本身没有展开完整的参数列表，但从服务示例和第三方封装库中可以确认核心参数：

*   **`key`（必填）**：Web服务API密钥。
*   **`ip`（必填）**：需要定位的IP地址。**与V3不同，V5不传`ip`无法自动定位请求方IP**。
*   **`type`（可选）**：服务示例中包含此参数（示例值为`4`），用于控制返回内容的类型，具体可选值需以开通权限后看到的完整文档为准。

### 输出字段（返回参数）

V5返回的字段比V3丰富，粒度从“城市”细化到了“区县”，并增加了坐标和网络信息。根据第三方封装库的总结，核心返回字段包括：

| 字段       | 说明                                                         |
| :--------- | :----------------------------------------------------------- |
| `country`  | 国家名称                                                     |
| `province` | 省份名称                                                     |
| `city`     | 城市名称                                                     |
| `district` | **区/县名称**（V5新增，粒度比V3更细）                        |
| `adcode`   | 行政区划编码                                                 |
| `location` | **经纬度坐标**（V5返回具体坐标，而非V3的矩形范围`rectangle`） |
| `isp`      | 网络服务提供商（如电信、联通等）                             |
| `ip`       | 查询的IP地址                                                 |

**关于坐标系的关键规则**：官方文档特别提示，当返回的`country`为“中国”时，接口返回的经纬度会转换为**高德坐标系（GCJ-02）**；当`country`不是中国时，则直接输出原始的**WGS-84坐标**。这意味着在处理海外IP时，不能对`location`做统一的国内坐标转换逻辑。

### 价格说明：无公开单价，以商务报价为准

V5**没有公开的按次计费标准**。作为需要商务咨询才能开通的高级服务，其费用不体现在高德公开的“基础LBS服务”价目表中。公开的“30元/万次”阶梯计价针对的是包含V3在内的基础服务。

网络社区中有用户提及“高级版套餐是**10万元/年**”的说法，但这属于非官方的个人经验分享，**不能直接当作V5的官方定价或唯一计费模式**。V5的实际费用（可能是固定年费、按调用量协议定价或与商业授权绑定的套餐）需要以工单沟通后高德给出的**正式商务报价**为准。

**总结来说**，V5的核心价值在于**IPv6、海外IP和区县级粒度**，代价是需要走商务流程，且价格不透明。如果你的软件只面向国内IPv4用户，且只需城市级信息，V3的自助流程和可预期的成本结构通常是更实际的选择。
