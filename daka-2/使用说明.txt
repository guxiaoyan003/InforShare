四、本版改动要点（2026-10-29）
1. 企业端「岗位招聘管理」与「岗位外包管理」合并为「岗位发布管理」：
   一个列表同时承载招聘岗位与外包用工需求，卡片/列表用类型标签区分
2. 「发布岗位」弹窗的「类型」下拉新增「外包」选项（全职 / 实习 / 兼职 /
   零工·日结 / 劳务派遣 / 外包）；类型筛选同步增加「外包」，可单独筛出外包需求
3. 发布时选「外包」，记录写入岗位外包业务线，核心业务「岗位外包」同步可见；
   编辑已有的外包记录时，其原用工类型（全职外包 / 驻场派遣等）不被改写
4. 企业端核心业务新增「数智化咨询」「AI培训」两个模块，现为
   项目外包 / 岗位外包 / 数智化咨询 / AI培训 四个
5. 「数智化资讯」统一更名为「数智化咨询」（登录页、菜单、面包屑、工单提示）
6. 浏览型核心业务页（如企业端 AI培训）补齐「查看详情」按钮，避免出现无操作按钮的卡片
7. 企业端「项目外包管理 → 发布需求」的「项目分类」下拉整体替换为：
   外部项目交付 / 项目外包 / AI培训 / 员工能力提升 / 业务数字化升级，
   顶部筛选「全部分类」同步替换；原演示项目已按新分类重新归类
8. AI培训卡片与课程类型调整：
   · 课程类型统一为「培训班 / 企业培训」两类，培训班额外标注线上 / 线下
   · 卡片信息层级：课程名称 → 机构名称 → 城市·区 | 周期 | 开课日期（用 | 分隔）
     → 课程内容 → 标签 → 联系人 + 按钮
   · 培训班 / 企业培训 / 线上 / 线下 统一为蓝色标签，标签左侧不再显示发布时间
   · 右侧价格为主价 + 灰色原价（如 ¥3600 原价 ¥4200）
   · 卡片新增「立即报名」主色按钮；企业端报名弹出确认框，确认后按钮变「已报名」
   · 详情抽屉中机构与讲师分两行展示
9. 数智化咨询与岗位/项目相关调整：
   · 数智化咨询卡片新增「申请咨询」主色按钮，提交后按钮变「已提交」
   · 数智化咨询页底部「咨询能力清单」整块删除；右上角「提交咨询需求」在企业端改为「刷新推荐」
   · 发布端管理新增「数智化咨询管理」，发布 / 编辑 / 停用 / 删除与其他发布页一致
   · 岗位类型删除「外包」，外包用工统一按「劳务派遣」归类（筛选、卡片、发布弹窗同步）
   · 项目外包的项目分类删除「AI培训」，现为 4 项：外部项目交付 / 项目外包 / 员工能力提升 / 业务数字化升级
10. 发布端管理交互统一（岗位发布管理 / 项目外包管理 / 数智化咨询管理）：
   · 每条记录的操作统一为「发布内容 / 撤下内容 + 查看详情 / 编辑 / 删除」
   · 查看详情、编辑、删除改为图标按钮（白底细边框，悬停变蓝调）
   · 删除图标默认红色描边 + 红色图标，悬停变红色填充 + 白色图标；删除不再限制记录状态
   · 数智化咨询页的「刷新推荐」由主色按钮改为描边按钮
