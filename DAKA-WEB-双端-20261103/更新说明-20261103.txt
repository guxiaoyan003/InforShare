一、本次改动

1. 登录页精简（按标注删除）
   · 删除标题下的「当前登录身份：个人端（大咖）· 首次登录将自动创建该端账号」；
   · 删除身份按钮里的「求职 · 学习 · 成长 / 招聘 · 发布 · 用工」副标题；
   · 删除「扫码登录 / 验证码登录 / 密码登录」三个胶囊按钮；
   · 删除演示账号提示块（演示手机号、验证码、一键填入）；
   · 删除底部「先不登录，随便逛逛」「管理员后台登录」以及单独一行的「忘记密码」。
   现在卡片里只有：标题 → 身份切换 → 输入项 → 登录/注册 → 登录方式文字切换 → 协议勾选。

2. 身份按钮改名
   · 「大咖个人端」「大咖企业端」（两枚按钮同样宽度，单行显示）。

3. 登录方式改为文字切换
   · 登录/注册按钮下方一行：手机验证码登录 | 扫码登录 | 忘记密码；
   · 点其中任意一项即切到对应登录方式，被点的那一项原位变成刚才的方式，可来回切；
   · 默认停在「账号密码登录」，所以首屏这一行就是「手机验证码登录 | 扫码登录 | 忘记密码」；
   · 「忘记密码」点击后提示演示环境不支持自助找回，不跳页。

4. 修复切换功能时闪登录页 + 每次弹「欢迎回来」
   · 根因：每个页面里都内嵌了一份蓝色登录层（#authPage），初始没有隐藏，
     页面 HTML 先被浏览器画了出来，要等 app.js（约 460KB）执行到末尾才隐藏，
     于是每次换页都会闪一下登录页；同时启动脚本每次都弹一次「欢迎回来，王旭」。
   · 处理：29 个页面的 #authPage 直接带上 hidden（首帧就不渲染），
     并删除启动时的「欢迎回来」提示。实测把 app.js 屏蔽掉（模拟 JS 未执行）时，
     页面首帧为空白，不再出现登录页。

四、打开方式
   双击 login.html 即可，无需服务器、无需联网。
   未登录时直接打开 personal/ 或 enterprise/ 下的页面，会以游客浏览器模式进入，
   投递 / 发布 / 报名 / 回复消息等写操作会跳转登录页，登录后回到原页面。

五、包内结构
   login.html            统一登录页
   personal/             个人端页面（岗位、项目、咨询、培训、私教、职业规划、实习、简历等）
   enterprise/           企业端页面（认证、发布管理、收到申请等）
   share/                双端共用页面（项目、外包、咨询、培训、消息、投诉等）
   admin/                管理后台（登录、审批、用户、内容、收费、配置、字典）
   assets/               css / js 公共资源
